# 暖心 Todo（Warm Todo）

> 帮助用户跨过复杂目标启动门槛的 AI 任务规划体验。

暖心 Todo 是一个移动端待办与习惯管理原型。它的核心不在于替代任何通用待办工具，而是帮助用户把模糊、复杂的目标转成“今天可以开始的一步”，并在写入待办前保留用户的编辑权与决定权。

## ✨ 当前核心闭环

1. 用户输入复杂目标，例如“准备考研”“准备秋招”或“开始健身”。
2. AI 识别目标类型，并针对求职、学习、工作、健身或生活目标追问关键约束。
3. AI 生成多层任务树，明确“今天先做”。
4. 用户可编辑第一步，也可编辑任务树中的全部步骤；可继续细化、保留、放弃或换一种拆法。
5. 用户确认后才写入待办，并可在总览中继续修改。

## ✨ 其他特点

- **待办 + 习惯双轮驱动**：任务管理与习惯养成融合，形成完整的自我管理闭环
- **四象限优先级**：内建艾森豪威尔矩阵（重要紧急 / 重要不紧急 / 不重要紧急 / 不重要不紧急），支持多级子任务（无限层级）
- **待办-习惯联动**：完成待办后引导习惯打卡，完成习惯后引导处理待办，双模块自然串联
- **温暖治愈风**：莫兰迪青绿主色 `#5BA898`、米白背景、大圆角、柔和阴影
- **AI 任务拆解与细化**：任务类型化追问、生成过程状态反馈、容错结构化解析、确认后写入待办
- **独立任务对话**：复杂目标可创建为独立对话，可切换、重命名和删除，减少多个目标混在同一窗口的干扰
- **已有习惯建议**：基于用户已有习惯和完成记录给出建议；不将其包装为针对当前任务自动生成的新习惯
- **长上下文记忆 + RAG**：用户画像与聊天历史持久化注入 LLM；客户端语义检索（embedding）为主，无接口时自动降级为本地词法检索

## 📱 移动端测试与预览

**零依赖，浏览器直接打开即可：**

```bash
# 方式一：直接在文件管理器中双击打开
index.html

# 方式二：用 Python 启动本地服务器（推荐，AI 功能需同源服务）
cd warm-todo-app
python -m http.server 8080
# 然后在浏览器访问 http://localhost:8080
```

在手机浏览器中访问在线预览链接时，页面会自动全屏适配，并处理底部安全区；电脑端保留手机框预览。

若使用 AI：每台测试设备的 API / 代理设置保存在该设备浏览器本地。请使用稳定网络，并确认代理健康检查可访问。

## 🧪 小规模可用性验证（N=8）

本项目完成了 8 位参与者的探索性可用性测试，测试目标为：**AI 是否帮助用户把复杂目标变成今天可开始的行动。**

| 观察项 | 本轮记录 |
|---|---:|
| AI 后“今天第一步”被评价为“很明确” | 8/8 |
| 相比手动，认为 AI 让开始行动更容易 | 7/8 |
| 愿意再次使用（非常愿意 / 比较愿意） | 7/8 |
| 认为步骤非常或比较贴合 | 6/8 |
| 认为写入前最终决定权在自己手中 | 8/8 |

测试记录中，手动拆解耗时均值约 12.5 分钟，AI 约 5.9 分钟；但任务难度、测试顺序和熟悉程度未控制，**不能据此声称 AI 提升效率**。

本轮能够支持的是探索性可用性发现，不能声称已验证用户留存、任务完成率、情感反馈效果，或相对竞品的优势。

### 基于测试反馈的迭代

- 从“只给框架”升级为“先追问关键约束，再细化任务树”。
- 增加“正在生成框架 / 正在细化计划”反馈，避免用户将等待误认为对话结束。
- 从只能编辑“今天第一步”升级为可编辑全部任务树步骤。
- 增加独立任务对话、重命名与删除；将“推荐习惯”澄清为“查看已有习惯建议”。

## 🤖 AI 后端（可选）

`server/` 提供了一个轻量 Fastify 服务端，为前端 AI 功能提供 Agent 能力：

- **ReAct 工具循环**：模型自主决定先查数据还是先拆解任务，前端可视化工具调用过程
- **RAG 检索**：`rag_search` 工具供 Agent 主动检索历史上下文；索引按语料哈希缓存
- **优雅降级**：无服务端时，前端可直连兼容 LLM API；也可填写密钥托管代理地址，避免在浏览器保存 API Key
- **设置可配**：设置页可配置 Embedding 模型 / 地址，并支持重建索引

```bash
cd server
npm install
npm start        # 默认 http://localhost:3000
```

前端通过 `callAgent` 桥接后端；未启动后端时自动降级，不影响基础交互。
